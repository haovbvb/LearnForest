# 识字森林

学习森林（LearnForest）家族里的中文识字 iPad App。商店和启动名是 **识字森林**。工程模块名是 **LearnForest**，Bundle ID 是 `com.learnforest.shizi`。

这不是英语森林 / Word Forest。英语线以后可以复用设计系统和本地档案，但用自己的内容包，不在这个目标里实现。

当前进度是 **Sprint 5：内容与质量 / TestFlight 准备**。12 节课、90 个字可以离线认字、做三种练习、看字卡和做一小轮复习。图和声音是家庭试用用的演示占位，正式插画和标准普通话还要按原来的资源 id 替换。家长验证、今日一览和本地数据清除已经接上。上传 TestFlight 需要用户自己的 Apple 账号，步骤见 [`docs/TestFlight清单.md`](docs/TestFlight清单.md)。

## 环境

- Mac 上的 Xcode 16.3 或更新版本（依赖 [GRDB 7](https://github.com/groue/GRDB.swift)，需要 Swift 6.1 工具链）
- 最低系统 **iPadOS 17.0**，目标设备只有 iPad
- 横屏优先，竖屏也能用

这套骨架是在没有 Xcode 的环境里提交的，没有跑过 `xcodebuild`。请在 Mac 上按下面步骤打开。

## 用 Xcode 打开

1. 克隆仓库，打开 `LearnForest.xcodeproj`。
2. 等 Swift Package 解析完成（GRDB）。如果没拉下来：File → Packages → Resolve Package Versions。
3. 选中目标 LearnForest，Signing 里选你的 Team。模拟器可以直接跑。
4. 运行目标选一台 **iPad** 模拟器（iPadOS 17 或更高）。
5. 关掉模拟器网络后再跑，确认不弹出联网提示。验收时看这些：
   - 首页「今日学习」打开「认识常见动物」的学习准备页，可以「开始正式学习」。认字页里计划中的空课仍然不能开始
   - 字卡上是大字、拼音、字义和演示色块图。「听一听」会播放短提示音，不是真人普通话。快速连点不会叠两声。切字、离开、退到后台都会停
   - 「下一个」之后回到首页，按钮变成「继续学习」，再进去还是刚才那一课、那一个字。杀掉 App 再打开也一样
   - 家长设置里打开安静模式后，进入字卡不会自动读，要点「听一听」。再打开「安静时轻量自动发音」才会自动出声
   - 家长把单次或每日上限改成 10 分钟后，到点出现休息页，没有惩罚，也没有把 App 锁死
   - 「我的字卡」里刚认过的字是「学习中」，不是「初步掌握」。换档案看不到这份进度
   - 有演示图的课，认完字后点「去做练习」。听音找图、看字找图都是点图；配对是先点字再点图
   - 点错只会看到「再看一看」，没有惩罚页。连点同一下不会记两次
   - 做完进入结果页：答对次数、初步掌握 / 稳定掌握 / 待复习，以及新得到的星星、贴纸、徽章。再做一次不会重复发奖
   - 只看字、不做题时，字卡里仍是「学习中」。答对两次以上才会变成「初步掌握」
   - 三个主题下 12 节课都可以开始正式学习。图和声音是色块和短提示音。若去掉某个字的图或声音，那一课就不能开始正式学习
   - 「我的字卡」可以按未学习、学习中、待复习、初步掌握、稳定掌握筛选。点一个字能看到大字、按设置显示的拼音、字义和配图，并能听一听
   - 还没有待复习或错得比较多的字时，「去复习」会说明现在不用复习。有的话，一轮最多 8 个看字找图。做完后掌握会更新，不另发贴纸。杀掉 App 再从字卡点「继续复习」，还是这一轮
   - 家长入口要先答对乘法。答错进不去。退到后台再打开，要重新验证。儿童端的认字页和字卡页没有家长入口
   - 家长页打开先看到今日一览：今天学过的字（带掌握）、还不熟或待复习、最多 3 个建议复习、今日有效时长、今日新得到的星星贴纸徽章。没有图表。做完一课再进来，掌握和「今日新得到」应和结果页对得上
   - 学习总览是当前档案的掌握数量、累计星星贴纸徽章，以及每节课的进度。换档案后这些数字跟着换
   - 把拼音改成不显示、安静模式打开、导航改成「仅首页大卡片」，关掉 App 再打开仍然如此。底栏和首页大卡片不会同时出现。关掉安静模式后，轻量自动发音也是关的
   - 清除当前档案的学习数据要先确认。档案和设置还在，课程还能打开，星星和进度没了。另一个档案不受影响。最后一个档案不能删除；有两个档案时，删除会连带清掉该孩子的答题和奖励，课程包还在

图标槽是空的，归档前需要放一张 1024×1024 的图。

## 本地优先

学习记录写在本机 SQLite（Application Support 里的 `learnforest.sqlite`）。没有网络也能打开已装进包里的课。V1.0 **不登录、不同步、不下载课程**。

表上留了 `syncStatus`、`schemaVersion`、`deviceId`、`deletedAt`。课程包清单里的 `remoteUpdate.enabled` 固定为 `false`。这些只是以后云同步和远程更新的位置，现在没有网络请求。

## 目录

```text
LearnForest.xcodeproj          Xcode 工程
LearnForest/
  App/                         SwiftUI 入口、根导航
  Features/Home                首页大按钮、家长入口
  Features/Learn               主题、课程、样例字
  Features/Cards               我的字卡、字详情、复习
  Features/Parent              成人验证、档案和设置
  Domain/                      档案、课程、学习记录、上架门槛
  Data/                        GRDB 迁移、Repository
  DesignSystem/                色板、大按钮、卡片
  Resources/                   图标槽、隐私清单、课程包位置说明
Content/core_chinese_v1/       打进 App 的本地课程包
Content/templates/             Excel/CSV 模板和导出说明
docs/                          TestFlight 清单
```

页面不直接碰数据库。档案走 `ChildProfileStoring`，学习记录查询走 `LearningStoring`。
