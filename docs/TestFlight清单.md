# 识字森林 · TestFlight 清单

家庭试用的代码已经可以离线运行。这一份给负责签名和上传的人。图和声音仍是演示占位，不是正式插画和标准普通话。

Bundle ID：`com.learnforest.shizi`。最低系统 iPadOS 17。只支持 iPad。

## 构建

1. 在 Mac 上用 Xcode 16.3 或更新版本打开 `LearnForest.xcodeproj`。
2. 等 Swift Package 解析完 GRDB 7.11。没有拉下来时：File → Packages → Resolve Package Versions。
3. 选中目标 LearnForest，Signing 里选你的 Team。模拟器可以先不签名直接跑。
4. 运行目标选一台 iPad 模拟器，或一台 iPadOS 17 及以上的 iPad。
5. 关掉网络再跑一遍，确认没有联网提示。
6. 要发给家人：Product → Archive，再 Distribute App → TestFlight。上传要用本账号的 Apple Developer 资格。仓库里的自动化环境没有 Xcode，也没有代传。

图标槽还是空的。归档前放一张 1024×1024 的图，否则上传可能被拒。

## 隐私文案要点

家长页「隐私与数据」已经写给家长看，提审和 TestFlight 说明可以沿用这些事实：

- 数据只在这台 iPad 上：儿童档案和设置、认字与练习进度、答题、掌握、星星贴纸徽章、每日有效时长。
- 没有账号，不上传，不同步，不内购。
- 汉字、演示图和提示音在随 App 安装的课程包里。清除学习数据或删除档案都不会删掉课程包。
- 删除档案和清除学习数据，清掉的是同一类：学习记录、答题、学习进度、奖励和有效时长。最后一个档案不能删除，但可以清除学习数据。
- 家长入口是乘法题，答案不保存。退到后台要重新验证。

## 必测场景

每条都在断网状态下做。

1. **断网续学。** 关掉网络，打开「认识常见动物」，认两个字后回到首页。按钮应变成「继续学习」，再进去还是这节课、这一个字。
2. **多档案。** 新建第二个孩子并切换。第一个孩子的字卡、奖励和继续位置不应出现。切回去还在。
3. **异常退出。** 练习做到一半，直接划掉 App。再打开，「继续学习」回到这节课的这一题，不会把同一下点两次。
4. **时长到点。** 家长把单次或每日上限改成 10 分钟。到点只出现休息页，没有惩罚，也没有把 App 锁死。每日已经够了，只能「再看一眼字」。
5. **安静模式。** 打开安静模式后，进字卡不会自动读，要点「听一听」。再打开「安静时轻量自动发音」才会自动出声。关掉安静模式后，轻量自动发音也是关的。
6. **家长验证。** 答错乘法进不去。答对后才能改设置。家长页开着时退到后台，再回来要重新答题。认字页和字卡页没有绕过入口。
7. **字卡和复习。** 按掌握筛选，点进一个字能看到字、拼音策略、字义和配图，并能听。没有待复习的字时，「去复习」说明现在不用复习。有待复习或错得比较多的字时，一轮最多 8 题看字找图，做完掌握会变，不另发贴纸。
8. **上架门槛。** 十二节课都能开始正式学习。这是因为 demo 图和声音齐全。缺图或缺音的课仍然不能开始。

## 已知限制

- 90 个字的图是色块，声音是短提示音，不是正式插画，也不是普通话朗读。`manifest.demoAssets` 为 true。替换时只换同名 `imageAssetId` / `audioAssetId` 文件，不要改汉字 id。
- 默认单次和每日时长是关闭，等产品确认 10 还是 15 分钟。
- 没有云同步、账号、内购、远程更新、描红和组词。
- 复习一轮不会发新的课贴纸。星星和徽章仍只在正式练习做完时、按原来的唯一约束发放。
- 首页「继续学习」回到认字课。复习做到一半要回「我的字卡」点「继续复习」。
